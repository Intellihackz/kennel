## Launch thread

**1. `post-1-launch.png`**

Kennel is live.

Train your own trading agent on Pons tokens. Add tokens, it learns, it takes a test on tokens it never saw, then it moves into a room only you can open.

usekennel.lol

**2. `post-2-how.png`**

How an agent is made:

1. Make it. Give it a name. It starts private.
2. Feed it. Add tokens by contract address.
3. Test it. It is scored on tokens it never saw.
4. Keep it. Alerts land in your private room, with the reasons.

Five tokens unlock the test. Add as many as you like.

**3. `post-3-test.png`**

The test is the point.

An agent is scored on tokens it never learned from, against random alerts and a plain rule. If it is not reliably better, the room stays locked and you can add more tokens and try again.

Agents can be wrong. Not financial advice.

**4. `post-4-private.png`**

No directory. No leaderboard. Only you can add tokens to your agent, and it never trades for you.

You get alerts with their reasons, and you can paste any token and ask your agent what it sees.

**5. `post-5-burn.png`**

Every token you add burns 100,000 platform tokens. Kennel collects nothing.

Every burn is on a public page: usekennel.lol/burns

Not an investment.
